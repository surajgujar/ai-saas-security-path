# Labs

Each week creates a folder here (`01-llm-internals/`, `02-vuln-agent-app/`, …). Every lab README should have:

1. **Goal** — which JD skill it proves
2. **Architecture** — Mermaid diagram
3. **How to run**
4. **Findings / results** — screenshots, metrics
5. **Mapping** — OWASP / ATLAS / control IDs

> ⚠️ Never commit API keys, tokens, or real company data. Add a `.env` (git-ignored) for secrets.
> Attack code stays against your own lab targets only.
