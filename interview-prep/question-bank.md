# Question Bank

Weekly technical questions live in each `weeks/week-XX` file. Below are cross-cutting ones.

## Case / whiteboard
- [ ] A Siemens BU wants to deploy an agent that reads customer service tickets, queries SAP, and emails customers. Assess it end to end in 45 min.
- [ ] Design identity and authorization for 200 AI agents built by different teams using MCP.
- [ ] Design a Shadow AI program: discover, assess, sanction/block, educate.
- [ ] A vendor's SaaS app with an OAuth integration into Microsoft 365 was breached. Walk through your first 24 hours.
- [ ] Design a secure model intake → fine-tune → deploy pipeline on GCP.

## Concept checks (answer in < 60 s each)
- [ ] OWASP LLM Top 10 — name all 10
- [ ] 5 MITRE ATLAS tactics unique to AI
- [ ] SSPM vs CASB vs CSPM
- [ ] Delegation vs impersonation in token exchange
- [ ] Why guardrails ≠ authorization
- [ ] What's an AI-BOM and who consumes it?
- [ ] EU AI Act: provider vs deployer
- [ ] Indirect prompt injection — 3 real-world vectors
- [ ] What makes an audit log "immutable"?
- [ ] BOLA in one sentence + fix
