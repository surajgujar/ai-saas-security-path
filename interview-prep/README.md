## Likely interview format (prepare for all)
1. **Recruiter / HR** — motivation, relocation/hybrid, notice period
2. **Hiring manager** — program thinking, stakeholder management, your AI security experience
3. **Technical deep-dive** — agent identity/authz, prompt injection defence, SSPM, GCP
4. **Case / whiteboard** — "Assess this AI product" or "Design controls for agent X"
5. **Team / culture** — mentoring, cross-cultural collaboration (Siemens is global, German HQ)
